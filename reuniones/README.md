# Reuniones

Deja aquí los audios de reuniones (por ejemplo `2026-11-18-pugazhenthiran.m4a`).
Los audios y las transcripciones **no se suben a GitHub** (`.gitignore`) y se transcriben en este computador, sin enviarlos a servicios externos.

Lo que sale de cada reunión (acuerdos, hoja de ruta) se resume en `ESTADO.md` y, si cambia la estrategia, en `PLAN.md`.
